# Design System · דניס ברצ׳בסקי / mplifyAI

> נבנה 7.11.26 מתוך mplifyai.com (CSS חי + סטיילים מחושבים). חומר הגלם ב-`source/` (`brand-extraction.md`, צילומי מסך, קבצי האתר).
> המבנה נשען על ה-design system של OctaLoom (רול הקרוסלה, מבנה 10 השקפים, קצב ויזואלי), עם הצבעים והפונטים של mplifyAI.
> **ערכים משנים רק ב-`tokens.css`.** כל התבניות מושכות ממנו.

## מה יש כאן

| קובץ | מה זה |
|---|---|
| `tokens.css` | צבעים, פונטים (@font-face מקומי), radius, הגריד והזוהר של האתר |
| `assets/logos/` | לוגו מלא + אייקון בלבד, ב-4 צבעים (ink / light / blue / glow), SVG |
| `assets/fonts/` | IBM Plex Sans Hebrew 300-700, IBM Plex Mono 400/500 |
| `assets/photos/` | התמונות של דניס (מגיעות בחבילה הפרטית, לא בריפו) |
| `templates/carousel.html` | 6 שקפים לדוגמה, כל סוגי השקפים |
| `templates/linkedin-cover.html` | באנר אישי 1584×396 |
| `render.py` | HTML ← PNG לכל שקף + PDF ללינקדאין, ובאנר ב-1x ו-2x |
| `out/` | פלטים |

```bash
python3 render.py carousel templates/<file>.html out/<slug>   # PNG + carousel.pdf
python3 render.py cover templates/linkedin-cover.html out/cover
```
לקרוסלה חדשה: להעתיק את `carousel.html` לשם חדש, להחליף טקסטים, להוסיף/למחוק `<section class="slide">` ולעדכן את הנקודות.

## צבעים

| טוקן | Hex | שימוש |
|---|---|---|
| `--ink` | `#090E1A` | רקע כהה (ההירו של האתר) |
| `--paper` | `#F6F7F8` | רקע בהיר |
| `--text` | `#0F1729` | כותרות וגוף על בהיר |
| `--text-muted` | `#344256` | גוף משני על בהיר |
| `--text-on-ink` | `#F8FAFC` | טקסט על כהה |
| `--blue` | `#2463EB` | ראשי: כפתורים, הדגשות על בהיר, מספרי שלבים |
| `--glow` | `#61A6FA` | **התכלת.** מילות הדגשה על כהה (כמו ״בלי להעמיס״ באתר) |
| `--marker` | `#DCEBFE` | מרקר מאחורי מילים על בהיר, טקסט בתוכו `#1842B4` |
| `--ink-line` / `--line` | `#1D283A` / `#E1E7EF` | קווים ופילים על כהה / בהיר |

**חוקי צבע**
- תכלת `#61A6FA` רק על כהה. על בהיר הוא לא עובר ניגודיות, שם משתמשים ב-`#2463EB`.
- כחול ותכלת הם אקסנט. רוב השקף שחור-לבן, כמו באתר.
- גרדיאנט: רק הגריד העדין והזוהר הרדיאלי הכחול של האתר, ורק על כהה. בלי גרדיאנטים צבעוניים אחרים.
- האתר שטוח: בלי צללים, בלי glassmorphism. הצל היחיד הוא סביב מוקאפ של טלפון/צילום מסך.

## טיפוגרפיה

- **IBM Plex Sans Hebrew** לכל דבר, עברית ואנגלית. כותרות 700, גוף 400.
- **IBM Plex Mono** רק לספרות ולטקסט לטיני קצר (״01״, ״02״). הפונט לא תומך בעברית, אז תוויות בעברית נשארות ב-Plex Hebrew 500.
- סקאלה בקרוסלה (1080 רוחב): הוק 112 · כותרת 76 · כותרת משנה 68 · גוף 44 · תווית 28.
- Frank Ruhl Libre מופיע באתר רק בטופס יצירת קשר. לא בשימוש בתוכן.

## לוגו

- `logo-light.svg` על כהה, `logo-ink.svg` על בהיר. `logo-blue` / `logo-glow` לשימוש נקודתי בלבד.
- `icon-*.svg` = הגג לבד, לשימוש כשאין מקום לשם (אווטאר, פינה, ווטרמרק).
- לא למתוח, לא לשנות צבע מחוץ לארבעת הקבצים, ולא לשים על רקע עמוס.
- בקרוסלה: למעלה משמאל, גובה 38px.

## קרוסלות

**קנבס 1080×1350 (4:5), RTL, מיושר לימין.** יוצא כ-PDF ללינקדאין (מסמך) וכ-PNG.

### שני מצבים, מתחלפים בתוך אותה קרוסלה
| | Ink (כהה) | Paper (בהיר) |
|---|---|---|
| רקע | `#090E1A` + גריד, זוהר בשקפים מרכזיים | `#F6F7F8` שטוח |
| כותרת | `#F8FAFC` 700 | `#0F1729` 700 |
| מילת הדגשה | תכלת `#61A6FA` | כחול `#2463EB` או מרקר `#DCEBFE` |
| גוף | לבן 82% | `#344256` |
| תווית עליונה | תכלת | כחול |
| מתי | הוק, מסר מזוקק, שבירת פריסה | הסבר, שלבים, CTA |

### מבנה (מהמערכת של OctaLoom)
1 הוק · 2 בניית מתח · 3-7 ערך עם פער סקרנות בסוף כל שקף · 8 התובנה המתקדמת · 9 המסר המזוקק · 10 CTA בלי חיכוך. פחות שקפים זה בסדר, הסדר נשאר.
**שקף שנראה כמו הקודם הורג את התנופה:** להחליף Ink/Paper ופריסה (טקסט, שלבים, צילום מסך, ציטוט) לסירוגין.

### רכיבים (כולם ב-`carousel.html`)
- **שקף 1:** הוק ענק, שורה אחרונה בתכלת. פוטר: תמונה עגולה + ״דניס ברצ׳בסקי״ + ״מייסד mplifyAI״ מימין, ״שמרו לאחר כך״ משמאל.
- **שלבים:** עיגולים ממוספרים ב-mono כמו ״איך אנחנו עובדים״ באתר, הנוכחי מלא.
- **פילים:** מסגרת דקה, מעוגלים לגמרי (כמו ״אוטומציות · חיבור מערכות · AI״ באתר).
- **כרטיס צילום מסך:** וואטסאפ, מייל, מסך עבודה. פרטים מוסתרים, בהסכמה.
- **CTA:** כפתור כחול מעוגל עם חץ, כמו ״קבעו שיחת התאמה״. בשקף האחרון בלי שם ובלי Save.
- **נקודות התקדמות** במרכז התחתון, הנוכחית מוארכת.
- בלי אמוג׳י, בלי אייקונים דקורטיביים. אייקונים, אם צריך, בסגנון lucide (קו 2px), כמו באתר.

## באנר לינקדאין

- 1584×396, רקע ink + גריד + זוהר, לוגו למעלה משמאל.
- **אזורים בטוחים:** תמונת הפרופיל יושבת למטה משמאל בממשק באנגלית ולמטה מימין בממשק בעברית, ובמובייל הצדדים נחתכים. לכן הטקסט נמצא ברצועה המרכזית (440px שוליים מכל צד).
- טקסט נוכחי (מ-`work/profile/headline-cover.md`, גרסה 3): ״הבאתם עוד לקוחות. / צריך עוד צוות?״ + שורת ערך + ״קובעים שיחה בנעוצים״. שורת הוכחה נכנסת רק אחרי השקת האפליקציה.
- להעלות את `cover@2x.png` (חד יותר).

## תמונות ויזואל לפוסטים

לפי האסטרטגיה: דניס אמיתי מול מצלמה, צילומי מסך אמיתיים, ובלי תמונות AI גנריות. כשצריך גרפיקה, היא נבנית מהתבניות האלה ולא מתמונת מודל.
